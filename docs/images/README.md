# 界面截图

根 README 的「界面预览」章节引用本目录图片。截图统一取自 1920×1200 的深色主题控制台，
**均已脱敏**（账号邮箱、组织名、真实用户名、服务器地址等已替换为示例值，请求量、Token 与
金额保留原值）：

| 文件 | 页面 |
| --- | --- |
| `input-providers.png`     | 输入 Provider：账号卡片、额度、筛选与批量导出 |
| `api-keys.png`            | API 密钥：同一 Key 多方案、调度模式与容灾链路 |
| `output-providers.png`    | 接入地址：四种协议端点与试跑命令 |
| `usage-stats.png`         | 用量统计：请求、Token、缓存、成本与延迟 |
| `traffic-logs.png`        | API 日志：逐请求链路与调度决策摘要 |
| `monitoring-overview.png` | 监控中心总览：拓扑、SLA、请求分布 |
| `monitoring-events.png`   | 监控中心事件流：请求 / 探测 / 签到 / 内核事件 |
| `models.png`              | 模型列表：搜索、能力过滤与 Provider 筛选 |
